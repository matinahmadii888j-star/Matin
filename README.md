# ربات تلگرام فیلم (کلید + کانال)

## این ربات چیکار می‌کنه؟
1. فیلم رو توی کانال خصوصی (SOURCE) آپلود می‌کنی، با یه کپشن به این شکل:
   - خط اول: اسم فیلم
   - خط‌های بعدی (اختیاری): چند کلمه درباره‌ی محتوا (ژانر، خلاصه‌ی دستی، سال، هر چی کمک کنه)
2. ربات خودکار:
   - با استفاده از هوش مصنوعی رایگان گوگل (Gemini API)، یه توضیح کوتاه و جذاب فارسی می‌نویسه (چون فیلم‌های شخصی معمولاً توی TMDB نیستن)
   - تلاش می‌کنه پوستر رو از TMDB پیدا کنه (اگه پیدا نشه، بدون پوستر ادامه می‌ده)
   - یه کلید کوتاه و یکتا می‌سازه
   - همه‌چیز رو توی Supabase ذخیره می‌کنه
   - کلید + توضیح + پوستر (در صورت وجود) رو توی کانال عمومی (DEST) پست می‌کنه
3. هر کاربر کلید رو خصوصی به ربات می‌ده → ربات فیلم رو براش کپی می‌کنه.

## متغیرهای محیطی لازم
فایل `.env.example` رو ببین. این‌ها رو باید توی Render تنظیم کنی:

- `BOT_TOKEN` — از BotFather
- `SOURCE_CHANNEL_ID` — آی‌دی عددی کانال خصوصی (منفی، مثل -1001234567890)
- `DEST_CHANNEL_ID` — آی‌دی عددی کانال عمومی
- `SUPABASE_URL` — آدرس پروژه Supabase
- `SUPABASE_KEY` — کلید service_role
- `GEMINI_API_KEY` — کلید رایگان از aistudio.google.com (بدون نیاز به کارت بانکی)
- `GEMINI_MODEL` — پیش‌فرض `gemini-2.5-flash`؛ نیازی به تغییر نیست
- `TMDB_API_KEY` — اختیاری، فقط برای پوستر؛ اگه نذاری، ربات بدون پوستر کار می‌کنه

## دیپلوی روی Render (بدون سرور شخصی)

### ۱. کد رو به گیت‌هاب ببر
اگه گیت/ترمینال نداری، از خود مرورگر گیت‌هاب استفاده کن:
1. برو به github.com و یه ریپازیتوری جدید بساز (مثلاً `movie-bot`) — می‌تونی Private بذاریش.
2. توی صفحه‌ی ریپو، دکمه‌ی **Add file → Upload files** رو بزن.
3. همه‌ی فایل‌های این پوشه (`main.py`, `db.py`, `tmdb.py`, `requirements.txt`, `render.yaml`) رو آپلود کن.
   (فایل `.env.example` رو هم می‌تونی آپلود کنی، مقادیر واقعی هیچ‌وقت توی گیت‌هاب نرو.)
4. پایین صفحه دکمه‌ی **Commit changes** رو بزن.

### ۲. سرویس جدید توی Render بساز
1. برو به render.com و با گیت‌هاب وارد شو.
2. **New → Web Service** رو بزن.
3. ریپازیتوری `movie-bot` رو انتخاب کن.
4. تنظیمات:
   - **Environment:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Plan:** Free
5. توی بخش **Environment Variables** همه‌ی متغیرهای بالا رو یکی‌یکی اضافه کن (مقدارهای واقعی خودت، نه نمونه).
6. **Create Web Service** رو بزن. چند دقیقه طول می‌کشه تا ساخته و اجرا بشه.

### ۳. جلوگیری از خاموش شدن (پلن رایگان)
پلن رایگان Render اگه ۱۵ دقیقه ترافیک نبینه، سرویس رو می‌خوابونه. برای بیدار نگه‌داشتنش:
- یه حساب رایگان توی uptimerobot.com بساز
- یه Monitor از نوع HTTP بساز که آدرس سرویس Render‌ت (چیزی شبیه `https://movie-bot-xxxx.onrender.com`) رو هر ۵ دقیقه پینگ کنه

## نکات امنیتی
- هیچ‌کدوم از این کلیدها (`BOT_TOKEN`, `SUPABASE_KEY`, `TMDB_API_KEY`) رو جایی پابلیک (گیت‌هاب پابلیک، چت‌های به‌اشتراک‌گذاشته‌شده و غیره) نذار.
- اگه فکر می‌کنی جایی درز کرده، توکن ربات رو با `/revoke` توی BotFather و کلید Supabase رو از تنظیمات پروژه Regenerate کن.
